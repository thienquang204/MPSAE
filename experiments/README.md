# Experiment entry points

- [CVPR 2027 paper reproduction](cvpr2027/README.md): frozen recipes, exact
  table/figure selections, local result import, training/evaluation and reporting.
- [Matched ResNet-50 comparison](extensions/matched_resnet50/README.md): CSR,
  CSRv2 and MPSAE with matched optimizer settings, two batches/seeds and resource
  profiling (72 SAE fits, 84 accuracy evaluations).
- [Extensions](extensions/README.md): Cityscapes and linear-probe segmentation.

Scientific code stays in `mpsae/`. Existing launchers and workspace layouts remain
supported. The paper catalog is the authoritative selection for reproducing the
supplied draft; broad historical defaults are not automatically paper settings.
